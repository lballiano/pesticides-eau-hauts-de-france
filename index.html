Contexte

Cette carte permet d’explorer les concentrations de pesticides et de métabolites dans l’eau distribuée dans les Hauts-de-France. Les zones sont colorées selon le code postal associé à la commune et la concentration maximale mesurée en µg/L.

Références affichées : norme européenne de 0,1 µg/L par pesticide et 0,5 µg/L pour les pesticides totaux. Valeur sanitaire provisoire de 3 µg/L pour les métabolites pertinents.

Comment lire la carte ?

Le gris clair indique l’absence de mesure pour la combinaison sélectionnée. Plus le bleu est intense, plus la concentration est élevée. Les zones dépassant la valeur de référence sont entourées. Survolez une commune pour voir le code postal associé ; cliquez pour consulter l’historique disponible du code postal.

Comment l’IA est utilisée ?

Le modèle ne remplace pas les analyses sanitaires. Il calcule dans le navigateur un score de priorité par code postal à partir des concentrations passées, des dépassements, de la tendance, de la variabilité et du manque éventuel de données.

Résultat : une couche priorité IA qui aide à repérer les zones à suivre, même quand la dernière valeur mesurée n’est pas la plus élevée de la carte.

Technique

Stack technique : HTML5, CSS3, JavaScript natif, Leaflet.js pour la carte interactive, GeoJSON pour les contours communaux, OpenStreetMap pour le fond cartographique et JSON local pour les mesures. L’application est statique : aucun serveur, aucune base de données et aucune étape de build ne sont nécessaires.

Utilisation de l’IA : l’application intègre un modèle local de scoring explicable, exécuté directement dans le navigateur. Il extrait des variables par code postal : concentration récente, maximum historique, fréquence des dépassements, pente temporelle, volatilité et complétude des données. Ces variables sont combinées pour produire un score de priorité de surveillance entre 0 et 100.

Les contours communaux sont récupérés à l’ouverture via l’API publique française geo.api.gouv.fr. Chaque commune est rattachée à ses codes postaux, puis croisée avec les valeurs mesurées agrégées par code postal.
