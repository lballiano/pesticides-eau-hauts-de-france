Context

This map allows users to explore pesticide and metabolite concentrations in drinking water distributed across Hauts-de-France. Areas are colored according to the postal code associated with each municipality and the maximum measured concentration in µg/L.

Reference values displayed: European limit of 0.1 µg/L per pesticide and 0.5 µg/L for total pesticides. Provisional health-based reference value of 3 µg/L for relevant metabolites.

How to read the map

Light gray indicates that no measurements are available for the selected combination. The darker the blue, the higher the concentration. Areas exceeding the reference value are outlined. Hover over a municipality to see its associated postal code; click to view the available measurement history for that postal code.

How is AI used?

The model does not replace health risk assessments. It calculates a monitoring priority score for each postal code directly in the browser, based on historical concentrations, exceedances, trends, variability, and potential gaps in the available data.

The result is an AI priority layer that helps identify areas requiring further monitoring, even when their most recent measured concentration is not among the highest on the map.

Technical Overview

Technology stack: HTML5, CSS3, vanilla JavaScript, Leaflet.js for the interactive map, GeoJSON for municipality boundaries, OpenStreetMap for the base map, and local JSON files for measurement data. The application is static: no server, database, or build process is required.

Use of AI: The application includes a local, explainable scoring model that runs directly in the browser. It extracts features for each postal code, including recent concentration, historical maximum, frequency of exceedances, temporal trend, variability, and data completeness. These features are combined to produce a monitoring priority score between 0 and 100.

Municipality boundaries are retrieved when the application loads through the French public API geo.api.gouv.fr. Each municipality is linked to its postal codes, which are then matched with measured values aggregated by postal code.
